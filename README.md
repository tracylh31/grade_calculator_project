# Grade Calculator Project

This Python program analyzes student grades for a single course.

## Featuers

- Stores student names and grades in a dictionary
- Calculates each student's average grade
- Assigns a letter grade based on the average
- Finds the student with the highest average
- Calculates the overall class average
- Counts how many students earned a passing grade

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:

```bash
python grade_calculator.py
